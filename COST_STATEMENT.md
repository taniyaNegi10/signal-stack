# SIGNAL STACK — COST STATEMENT

## 1. Project Overview

Signal Stack is a Python-based Company Intelligence and Executive Briefing Engine developed using open-source technologies.

The current implementation runs locally without requiring paid cloud infrastructure or paid AI API services.

## 2. Technology and Cost Breakdown

| Component | Technology | Cost |
|---|---|---|
| Programming language | Python | Free |
| User interface | Streamlit | Free |
| Database | SQLite | Free |
| Web extraction | Requests, BeautifulSoup | Free |
| RSS processing | Feedparser | Free |
| Data processing | Pandas | Free |
| Scheduling library | APScheduler | Free |
| PDF processing | pypdf | Free |
| Excel processing | openpyxl | Free |
| Version control | Git and GitHub | Free tier |
| Code editor | VS Code | Free |

## 3. Infrastructure Costs

The current prototype uses:
- Local development environment.
- Local SQLite database.
- Local Streamlit application.
- Permitted public webpages and RSS feeds.

No paid hosting service or paid API subscription is required by the current local implementation.

Internet access is required for collecting information from accessible public sources.
